# Wizard Shop Dataset 🧙‍♂️

The Wizard Shop Dataset is an educational collection of tabular data containing information about a fictional wizard shop. Its goal is to help demonstrate some of the core data analysis principles in an approachable format. 

The dataset consists of three `.csv` files:

- `data/wizard_shop_inventory.csv`: A list of products with prices, item quality, and other attributes. 

- `data/magical_items_info.csv`: A small table with typical price, quality, and where the item is typically found.

- `data/items_prices_timeline.csv`: Average daily prices of each product category.

The dataset is dedicated to the public domain ([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)).

I created this dataset to help me quickly test out various data science packages, techniques, or approaches. When designing the dataset, I had four objectives: (1) easily understandable data, (2) diverse data types, (3) open format, and (4) enable free usage of the dataset without having to think about licensing.
